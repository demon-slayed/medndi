# MedNDI demo data

These JSON files feed `npm run seed` (scripts/seed.js). The hospital and hotel names and locations are real. The doctors are fictional, and the images are generic stock photos (Unsplash and randomuser.me), not photos of the named hospitals or hotels. Stats, ratings, bed counts, prices (INR), success rates and distances are illustrative estimates for demo use only. Do not treat them as quotes or as claims made by any hospital or hotel, and confirm all details with the institution before relying on them.
